## 当前状态（2026-10-24）

已在 Huawei Pura X Max／麒麟 9030 Pro（16+512、API 26）和 HPR-W72／麒麟 X90（32 GB、API 26）验证本机 NPU 加速。系统通过 NNRT 开放的加速设备、页面尺寸、输出质量和速度检查均满足时自动启用；不满足时回退 MindSpore Lite CPU。部分算子仍可能由 CPU 执行，其余机型尚未完成真机验证。

麒麟 X90 使用现有代码即通过横竖页校验，复用模型时 Worker 完整着色分别为 **1.516／1.591 秒**，强制 CPU 为 **4.956／5.036 秒**。每种场景为单次样例测量，未做该设备长测。详细记录见[麒麟 X90 真机验证](../harmony-book-ai-engine/docs/comic-colorizer.md#麒麟-x90-真机验证2026-10-24)。

连续页复用 NPU 模型，并使用 C++ 合成线稿与颜色。1350×1920 原页及旋转横页的 Worker 完整着色实测分别为 **2.103 秒、2.241 秒**；CPU 回退分别为 **5.012 秒、5.059 秒**。首次加载和 CPU 对照校验约 8.6～8.7 秒。上述计时包含解码、推理、合成和 JPEG 编码，不含下载、模型资源解包、队列等待及缓存写入，也不代表所有漫画页的固定耗时。

三份模型原始体积合计约 176.25 MiB，不再随应用打包。首次开启彩色阅读或单页着色时提示下载，确认后从私有 OBS 下载到私有目录并逐份校验长度与 SHA-256；完成后可离线使用，图片不上传到着色服务。取消或失败不会开启着色，重试复用已完整下载的模型，旧版已解包模型可校验后沿用。输出长边最多 2048，JPEG 质量 95。尺寸范围、运行流程、日志说明、历史问题和复现方法统一维护在 [子库着色文档](../harmony-book-ai-engine/docs/comic-colorizer.md)。

阅读预热现已接入：会员开启彩色阅读后提前检查已下载的 CPU 模型并准备 Worker，真实页面只准备对应方向的 NPU 模型；空闲模型保留 120 秒，后台、关闭／暂停、权限失效和内存压力时释放。当前页优先于预取及准备；成功的加速校验按模型和系统版本保存，最多复用 7 天。首次校验仍保留，重启仍需重新加载模型；本段描述实现策略，不代表上述历史性能表已覆盖全部新场景。

本轮真机服务测试中，重启首张 3.980 秒、紧接下一张 2.053 秒，均未重复 CPU 对照。连续运行约 23 分钟后因进入后台取消，按用户选择结束长测，保留结果，不计为完整 30 分钟通过；保留模型与主动释放各 18 次的耗时 P50 为 2.161／3.749 秒。完整口径、内存温度采样及限制见 [AI 引擎测试记录](../harmony-book-ai-engine/docs/comic-colorizer.md#连续运行的部分验证2026-10-24)。

## 宿主边界与检查

主应用保留页面、会员策略、`AppAiHost` 适配器、Worker 启动入口和设备测试。NPU 选择、CPU 回退、模型与原生合成在 AI 子库内实现。完整检查执行 `npm --prefix harmony-book-ai-engine test`；主应用的 `scripts/comic-colorizer-check.mjs` 另外覆盖页面菜单集成。Node 检查不替代 NPU 和 C++ 真机验证。

## 模型发布与安装包瘦身

模型文件保留在子库 `models/comic-colorizer/`，不属于 HAR 的 rawfile。许可证和模型描述仍随应用提供。服务端签发 30 分钟有效的 HTTPS 下载地址；App 中固定长度与 SHA-256，不信任远端任意模型替换。预热和推理不会发起模型下载。模型存于 filesDir，不随图片缓存清理。

部署步骤见 [服务器更新说明](../server/scripts/comic-color-model-update/README.md)。需要先上传模型并发布新接口，再分发客户端。
