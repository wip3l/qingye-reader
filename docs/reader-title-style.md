# 标题分段与强调效果

入口：阅读字体 → 标题字体设置。

## 标题布局

标题位置可选左对齐、居中、右对齐，默认居中，独立于正文对齐方式。
标题上、下边距分别支持 0～120 vp，步长 1，默认均为 0。
边距附加在现有页面边距和段间距之外；分段标题视为一组，只在整组标题之前、之后留白。
分页跨页时不在续页重复添加标题边距，也不会为大边距产生空白页。
设置页预览、阅读预览、主题排版预览、分页和滚动阅读均使用对应的标题位置与边距。

## 标题单页

“标题布局”内的标题单页开关默认关闭。开启后，每章完整标题（包含所有分段）独占一页，
正文从下一页开始。标题继续使用所选对齐、上下边距、字体和强调效果；标题过长时，
按可用页高整体缩小标题、留白及其装饰，保留全部标题文字，正文大小不变。
卷标题和章前插图不会与章节标题挤在同一标题页；仅含标题的章节不会生成空白正文页。
滚动阅读会为标题预留一屏高度；阅读预览可以在标题页与正文页之间切换。
该开关随标题配置保存、恢复并进入主题分享包。

## 标题分段

分段默认关闭，另支持三种模式：

- 按位置：在指定字数后换行，汉字、标点、空格和一个 Unicode 码点各计一个字，范围 1～160。
- 按标记：在第一个匹配标记后换行，保留标记。
- 按正则：在第一次非空匹配的末尾换行，保留匹配内容。

第二段字号为标题字号的 0.5～2.0 倍，步长 0.1；标题行距为 0～40 vp，步长 1，只用于分段标题，未开启分段时标题换行沿用正文行距。
初始值为 1.4 倍和 14 vp。切换模式会保留各模式输入内容。

输入无效、未匹配、位置超出标题或分段后任一段只有空白时，保留原始标题。
分段只调整标题块的排版，不改写原文、复制内容、朗读文本和阅读进度偏移。

## 强调效果

默认“无强调”，可选择“跟随主题”或“自定义”。自定义复用正则字体的设置控件，
支持独立设置文字色、高亮色块、强调气泡、气泡风格和含透明度的颜色。
气泡风格继续遵循现有主题使用权限。

标题强调不依赖“启用正则字体”。开启标题自身的强调时，标题范围优先使用标题设置，
正文及标题范围之外的正则规则继续生效；选择无强调时保持原有正则命中行为。
带端饰的标题气泡在每个视觉行分别封口，换行不会截断端饰。

标题预览位于标题设置最前面，支持修改示例、切换长短标题示例及打开阅读预览。分段方式和标题对齐用分段按钮直接切换；按标记、按正则提供常用预设，并用示例标题即时显示两段的拆分结果。
设置随主题阅读排版档案保存，可进入主题排版草稿和主题分享包；
保持现有设备排版同步策略，不由云端阅读偏好覆盖本机标题排版。
