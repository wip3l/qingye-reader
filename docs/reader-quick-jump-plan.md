# 小说与漫画阅读页「快速跳转」实施方案

日期：2026-10-29。状态：方案已确认，功能已实现。

## 推荐交互

将小说阅读页设置项「使用章节快速跳转组件」改为「使用快速跳转组件」，说明改为「在章节与全书百分比之间切换，保留上一章、下一章按钮」。默认仍为章节模式，记住用户上次选择。

在现有底部浮动操作栏上方放置固定两行的快速跳转卡片：

- 第一行：左侧中性分段按钮「章节 / 百分比」，右侧显示「88 / 240 章」或「62.6% · 全书」。
- 第二行：上一章按钮、进度滑杆、下一章按钮。两个模式下箭头始终表示相邻章节。
- 章节模式按章吸附；百分比模式范围 0–100%，步长 0.1%，保留一位小数。
- 拖动只更新临时目标与浮动提示，不加载正文、不保存进度、不打断朗读。松手或点击轨道后打开「确认跳转」。确认才执行，取消恢复实际位置。
- 章节确认信息显示章节标题，定位该章第一页。百分比确认信息显示全书百分比、目标章节和预计章内比例；只有已获得有效分页结果才显示目标页码。
- 切换模式只改变定位方式，清空尚未提交的预览。弹出确认框、加载或分页定位期间禁止重复操作；同一实际位置不重复跳转。
- 成功后短暂提示实际到达位置。失败保留原阅读锚点，撤销临时目标并允许重试。

范围扩展至漫画：复用统一组件与确认流程，漫画显示“话数 / 百分比”，左右按钮始终切换上一话、下一话。话数模式跳到该话开头，百分比按各话等权、话内图片页进度定位。

## 视觉和布局

沿用 ReaderFloatingMaterialBar / ReaderMaterialPanel 的系统材质、圆角和语义底色；新卡片建议约 104vp 高，第一行分段控件触摸区域至少 44vp，第二行约 48vp。两种模式高度相同，切换使用 160–200ms 的选中底板平移和轻微文字淡入，不让整张卡片形变。

滑杆已读轨道与确认主操作使用当前主题强调色。分段按钮采用中性选中底板和语义文字色；普通箭头、正文与辅助文字使用对应主题语义色。主题色按钮文字通过 ThemeRuntime.onAccentColor() 取得适配前景。朗读、自动滚动快捷按钮继续使用一致的中性图标与沉浸材质。

沿用 readerFloatingBarWidth() 与 readerFloatingBarLeft() 的手机居中、平板靠操作侧规则。修改统一的浮层高度计算，联动 tooltip、朗读胶囊、自动滚动胶囊和手势排除区，不能只把卡片画高。窄屏放不下章节标题时优先保留模式和数值，完整标题放到浮动提示；大字体允许标题区域增高并同步计算占位。

原型采用示例蓝色主题，可在 HTML 中更换为棕色；它不代表应用中固定这些色值。视频是本地绘制的设计原型，不能据此认定 HarmonyOS 原生材质效果或真机布局已经验证。

## 百分比定义与反算

复用 entry/src/main/ets/core/reader/ReaderInfoBarModel.ts 中 ReaderInfoBarText.bookPercent() 的既有含义：

`p = 100 × (chapterIndex + (pageIndex + 1) / pageCount) / chapterCount`

这是章节等权、章内按页的全书进度，不是全书字数占比，也不是已下载章节占比。初期不新增全书字数扫描和下载；这样无需预加载整本网络小说。字体、排版、双页模式可能改变页级落点，实际值始终取信息栏的同一计算函数。

将映射抽为纯函数，设 `N=chapterCount`，输入 `p` 限制为有限数值且在 0–100 内：

1. `p=0` 显式到第一章第一页；`p=100` 到最后一章最后一页。
2. 对其余值，`q=p*N/100`；为和现有「当前页末端进度」一致，`chapterIndex=clamp(ceil(q)-1,0,N-1)`，`chapterRatio=q-chapterIndex`。浮点误差应使用统一容差处理。
3. 目标章完整分页得到 M 页后，`pageIndex=clamp(ceil(chapterRatio*M)-1,0,M-1)`。再按现有双页逻辑 normalizeReaderSpreadPageIndex() 归一化。
4. 跳转后显示实际页对应的百分比。请求 0% 会到书首，但信息栏现有页末端口径可能显示一个非零的小数，不应伪造 0%；必要时提示「已到书首」。若之后希望从 0% 连续显示，则需另行统一修改信息栏口径。

章节边界按上述规则落到前一章最后一页。例如 240 章的 62.5% 对应第150章末页，62.6% 对应第151章的约24%处；该章25页时落第6页。原型百分比跳转使用后一个例子。

拖动预览只需章节目录，不能为了显示页码触发网络请求。没有目录时禁用整个定位区；仅一章时章节滑杆禁用，百分比仍可在章内定位。未完成分页、换源、目录刷新或切书后必须废弃旧目标，避免异步结果覆盖新阅读位置。

## 加载、分页和朗读衔接

当前 confirmMenuChapterJump() 已负责确认，jumpToMenuChapter() 通过 jumpToReaderPositionKeepingTts(chapterIndex,pageIndex) 跳转；后者在加载后立即保存并可能恢复朗读，因此不能将未知目标页简单填成 0 后直接复用整个流程。

实施时为跳转链路增加明确的比例目标（chapterIndex、chapterRatio、bookUrl、requestToken 和目录版本快照），或抽出共同的目标解析流程。统一完成以下事务：

1. 确认前保存原阅读锚点，确认后暂停已有自动滚动并按既有规则暂停朗读。
2. 加载目标章，在完整分页结束且 token、书籍、章节仍匹配时计算目标页。不要把增量分页的临时页数当作最终页数。
3. 提交规范化页位置，刷新正文和进度锚点，再保存进度，最后恢复此前活跃的朗读；自动滚动仅在目标稳定且仍符合启用条件时恢复。
4. 外部悬浮朗读会话目前接收具体 chapter/page，要在该会话侧支持同样的比例解析，或通过同源分页解析出有效页再提交；不能仅修改主阅读页而忽略正在镜像的会话。
5. 加载失败、目录更新、关闭页面或新跳转覆盖旧跳转时，作废旧 token，释放忙碌状态，避免错误进度存盘和朗读从错误页恢复。

章内百分比定位等待目标章节完整分页，可能比单纯跳章慢。提示「正在定位…」，只为本次目标章补齐分页；无需整个书籍提前分页。

## 实施顺序与验收

1. 先实现映射纯函数和模式持久化，覆盖 0%、100%、章节边界、单章、非法值、浮点边界与页数取整。
2. 完成共享 UI 和两种材质路径；验证开关、切换、拖动、确认、取消和布局占位。
3. 接入待定目标与完整分页回调，验证加载失败、切书竞争、换源、目录变化、双页和朗读会话。
4. 更新两份说明文档，运行对应检查后，按 docs/local-device-development.md 的本地流程编译验证；用户要求安装时安装到默认 HPR-W72。

必须通过的体验验收：

- 拖动、切换模式和取消均不写阅读进度；确认仅提交一次。
- 成功后组件、阅读信息栏和重开书籍位置一致；章节模式准确到章首。
- 浅色、深色、多种主题色下文字可读；两个中性快捷入口不被主题色染色。
- 手机窄屏、平板左右操作侧和大字体没有遮挡、裁切和触摸重叠。
- 离线未缓存章节失败可恢复，快速重复操作和异步旧结果不会覆盖当前阅读。
- 漫画使用话数与全书百分比定位；条漫、单页和双页模式共用目标解析，双页对齐包含目标图片的页面组。旧配置中的组件开关保持原值。
